# Custom system prompts

Place `.md` or `.txt` system-prompt files in this directory, then select `custom file`
in Prompt Director and enter the filename in `system_prompt_file`.

The selected file replaces Prompt Director's complete built-in system prompt.

`minimax_reference_manager.md` is the repository-owned copy used by the
`MiniMax Reference Manager` preset. It is kept verbatim so it can be compared with the
source node by hash.
